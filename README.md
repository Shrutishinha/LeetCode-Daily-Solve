## 🧠 Core Problem-Solving Patterns

### 🔹 Two Pointers
- Sorted arrays
- Pair-sum problems
- Palindromes
- In-place modifications

### 🔹 Sliding Window
- Subarrays and substrings
- Frequency constraints
- Longest / shortest window
- Fixed and variable-size windows

### 🔹 Prefix Sum
- Range queries
- Subarray sums
- Cumulative calculations

### 🔹 Hashing
- Frequency counting
- Duplicate detection
- Fast average lookup
- Grouping elements

### 🔹 Binary Search
- Sorted data
- Search-space reduction
- Minimum / maximum feasible answer

### 🔹 Dynamic Programming
- 1D and 2D DP
- Knapsack
- Subsequences
- Grid DP
- Memoization and tabulation
